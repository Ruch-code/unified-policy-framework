## Auth System

### AuthContext.jsx
- `TOKEN_KEY = 'compliance_token'`
- `api()` - wrapper for fetch with auth header
- `AuthProvider` - provides `user`, `loading`, `login`, `logout`, `changePassword`, `api`
- Token stored in localStorage, validated via `/api/auth/me` (Netlify Function)

### RequireAuth.jsx
- Checks `user` and `loading` from `useAuth()`
- Shows loader while `loading`
- Redirects to `/login` with `state.from` if not authenticated
- Checks `admin` role if `admin` prop is true

### Netlify Functions (Auth)
```
netlify/functions/auth-login.mjs     → POST /api/auth/login
netlify/functions/auth-me.mjs        → GET /api/auth/me
netlify/functions/auth-register.mjs  → POST /api/auth/register
netlify/functions/auth-password.mjs  → POST /api/auth/password
netlify/functions/auth-reset-request.mjs → POST /api/auth/reset-request
netlify/functions/auth-reset-confirm.mjs → POST /api/auth/reset-confirm
```

### Shared Auth Module
```
netlify/functions/_shared/auth.js
  → connectDb(), User model, signToken(), verifyToken(), authUser(), authAdmin()
  → JWT with HS256, 7-day expiry
```
