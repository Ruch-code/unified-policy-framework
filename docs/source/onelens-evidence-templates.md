# OneLens Evidence Template Library

Generic, reusable evidence and document templates for SOC 2, ISO/IEC 27001:2022, HIPAA and GDPR audits. Every item below is written as a neutral template that any organisation can adapt. No platform, vendor or client references are included.

**Framework tags:** `SOC2` | `ISO27001` | `HIPAA` | `GDPR`
**Slug** is the suggested file name and URL path on the site: `/templates/<slug>`

### Usage notes
- Each template should open with: Version, Owner (role, not name), Approver, Effective date, Next review date, Framework mapping.
- Placeholders use `[Organisation Name]`, `[Role]`, `[System]`, `[Date]`. Never store real names, emails, IDs or account numbers in a template.
- Evidence templates (logs, records) should include a "Screenshot / attachment" slot and a "Reviewed by / Date" sign-off row.
